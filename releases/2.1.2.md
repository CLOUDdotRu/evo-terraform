## provider minor 2.1.2

### Добавлено
1. Таймауты в ресурсы и датасорсы
2. `mulitAZ` для `Redis cluster`
3. Кастомный ресурс `GroupMembership`, который позволяет управлять связью между группой и пользователем
4. В `artifact registry` добавлен тип `registry npm`
5. Передача `endpoints` теперь не обязательна - по умолчанию будут использоваться актуальные значения для прода в `public api`
6. Тип памяти для видеокарт GDDR7 для `baremetal`
7. Ресурс и датасорс `dataplatform cluster`
8. Поддержка `deprecated message`

### Исправлено
1. Ошибка с неконсистентным состоянием в `postgres cluster` с полем `pg_wal_gb`
2. Ошибка с пересозданием кластера при обновлении backup `schedule/retention_policy_days`
3. Проблема с обновлением `flavor_id` в `nodepool`
4. Проблема с пересозданием `disk`
5. Проблема с `required vm` в `interface`
6. Проблема с пересозданием VM
7. Фикс бага с зонами в `mk8s`
8. Фикс бага при выполнении Read для cloudru_evolution_obs_bucket
9. Проблема с пересозданием ресурса network_interface

### Документация
1. Обновлена документация для большинства ресурсов и датасорсов
2. Добавлена документация для таймаутов в ресурсах и датасорсах
3. Добавлена инструкция по использованию таймаутов
4. Добавлены недостающие порты в эндпоинтах в примере `main.tf`
5. В примере ресурса `cloudru_evolution_iam_api_key` исправлено поле `product_codes` и добавлена информация о том, где взять все варианты значения этого поля
6. Добавлен пример для `postgres cluster product_type`
