# cloudru_evolution_kafka_topic_collection (Data Source)



## Example Usage

```terraform
data "cloudru_evolution_kafka_topic_collection" "datasource_topic" {
  cluster_id                   = "00000000-0000-0000-0000-000000000000"
  page_size                    = 20
  filter_by_partial_topic_name = "some_topic_name"
  # Позволяет переопределить дефолтный таймаут провайдера для определенного метода. Если нужно указать бесконечный таймаут, то нужно указать например 0s, тогда таймаута не будет.
  timeouts {
    read = "10m"
  }
}

output "data-topic" {
  value = data.cloudru_evolution_kafka_topic_collection.datasource_topic.topics[0]
}
```
